# China passenger rail data

CN uses the same `compact-v1`, station tables, N02-shaped solver resources,
display builder and physical-junction registry as the other shipped regions.
The filename follows the existing package convention; the actual source snapshot
is **2026-10-17**, and the package version is **2026.10.18**.

The published snapshot contains 3,991 evidenced line/branch/path records,
17,594 intervals and 21,573 station memberships, including 2,715 of the
3,404 official telecodes. These are not counts of distinct complete railways.
All 3,991 published path records and 14 reviewed physical sections were checked against original node coordinates
and consecutive source-way membership/versions before generating 3,719 CN-only
same-node physical junctions. Two additional reviewed original-track lead-ins retain exact original adjacency and zero attachment. Four ambiguous endpoint records were withheld.
Raw N02 station resources additionally retain three genuine reviewed memberships,
including newly exposed official identity PSW: 21,576 features and 2,716 official
identities; the compact membership and telecode counts above remain unchanged.

## Exclusive dataset ownership

The whole Guangzhou–Shenzhen–Hong Kong HSR, including the Hong Kong section and
Hong Kong West Kowloon (`XJA`), belongs to **CN only**. Other Hong Kong rail
belongs to HK. **All Macau LRT, including Hengqin, belongs to MO only.**
These are product dataset assignments, independent of geographic boundaries.
There are no cross-region physical graph links or shared CN/HK/MO records.

## Station order, tracks and uncertainty

The reviewed HSR order is 广州南 → 南沙北 → 虎门 → 光明城 → 深圳北 → 福田 → 香港西九龙.
Elsewhere, ordered passenger relation members and stop areas are OSM evidence;
they are not labeled as official national timetable data. Named infrastructure
uses its own source track graph and source station memberships. Separate
branches remain separate. Station markers and exact original track-node anchors
are recorded independently. Candidate selection near a station does not create
an edge: every published edge is consecutive in an original active member way.
Infrastructure `route=railway/tracks` station-member inventories are not treated
as passenger stop order; their order is derived from original track adjacency.

Parallel platform tracks remain separate candidates when selecting a continuous
ordered path. Original node IDs are retained by both runtime solvers so different
nodes at equal coordinates do not become a junction. Cross-line junctions require
the same original OSM node and independently verified adjacent source ways on
both sides. Same names, nearby coordinates, transfer passages and station groups
do not connect physical tracks.

`cn-2025.sources.json` retains per-line station membership, original interval
node/way lists, versions and source relations. `cn-coverage.json` records
unresolved or withheld source records and unpublished official telecodes.
**National completeness is not claimed.** Missing topology, operator identity,
station membership or connected intervals remain explicit gaps, without straight
connectors or invented services. The current package is a passenger railway
network, not a current train timetable or an engineering survey.

Chinese names and official pinyin are separate fields. Missing English remains
blank; explicit OSM English is marked as an OSM candidate, and reviewed MTR
English is scoped to this corridor. OpenCC-derived traditional orthography is
identified as derived. OSM colours or local UI fallbacks are not invented official
brand evidence. Geometry stays WGS84; MapKit presentation uses the existing
service datum probe mechanism, separately from dataset ownership.

## Rebuild

Restore the pinned PBF and its acquisition/header records under
`railway-sources/local/china/osm/`, and the official source records under
`railway-sources/local/china/evidence/official-20261018/`. From the repository root:

```sh
python3 app/scripts/railway/extract-china-osm.py \
  --pbf railway-sources/local/china/osm/china-261017.osm.pbf \
  --output railway-sources/local/china/osm/china-261017-rail.sqlite3
python3 app/scripts/railway/build-china-rail-package.py \
  --database railway-sources/local/china/osm/china-261017-rail.sqlite3 \
  --official-dir railway-sources/local/china/evidence/official-20261018 \
  --root . --output-dir /private/tmp/china-package-review
python3 app/scripts/railway/build-china-physical-junctions.py \
  --database railway-sources/local/china/osm/china-261017-rail.sqlite3 \
  --package /private/tmp/china-package-review/app/public/rail/cn-2025.json \
  --source-topology /private/tmp/china-package-review/app/public/rail/cn-2025.sources.json \
  --registry app/data/physical-rail-junctions.json --replace-generated-cn \
  --reviewed-connections railway-sources/china-reviewed-connections.json \
  --output /private/tmp/china-package-review/physical-rail-junctions.json
```

The scratch layout permits review before replacing published artifacts. Native
resource copying uses the existing display-network builder. Raw downloads remain
local; published topology evidence and attribution remain with the package.
