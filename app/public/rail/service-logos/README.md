# Japanese limited-express logo artwork

Assets in this directory depict genuine service marks sourced from railway
operators or Wikimedia Commons. PNG files are standalone marks (flat or vector artwork from operators or
Wikimedia Commons, preferred whenever one exists); the JPEG files are close-up
photographs of marks on the trains, kept only where no flat artwork was found. The photographed marks are
retained as photographs, cropped where needed, resized and recompressed for the app. Source links,
authors, licenses and changes are recorded below.
