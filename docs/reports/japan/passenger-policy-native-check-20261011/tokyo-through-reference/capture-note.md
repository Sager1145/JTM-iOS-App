# Tokyo north/south conventional railway baseline

Captured through CUA in the existing manual Hakone Inspector instance. No build, clone, geometry, data or review verdict changed. Default full capture was left running throughout. Manual instance remains on Tokyo central, north-side 東北線-2#11 viewpoint 5/5 at z18.

Package read confirms 東北線-2 and 東海道線 both use Tokyo code 003766 at [139.7671827,35.6811274]. Other Tokyo members use distinct physical coordinates for 総武線, 丸ノ内線 and both Shinkansen families; these were not merged or treated as conventional through track.

Each PNG has a matching .ax.txt carrying camera, line selection, mode and manual output context. Each overlay/basemap pair retained the same camera; only inspector overlay visibility changed. Apple’s own black railway strokes remain visible in the basemap image, including parallel tracks and station throats. Apple’s coloured transport labels are also basemap content.

This is baseline single-line Inspector evidence. It does not show production family composition, prove which platforms connect, establish a general closest-track rule, or demonstrate that the proposed common central point repair has been implemented. Sobu, Keiyo and Shinkansen remain independent subjects.
