## 跨午夜结构修正和自动重建

銀河和歌山到23:42、发0:30需要不同日期偏移。`stop_times`新增独立`arrival_day_offset`、`departure_day_offset`，未设置时继承旧`day_offset`。时刻覆盖记录同样具有独立偏移，并继承对应到达或发车侧。无对应时刻的偏移会被拒绝；已有25:03表示法不能再叠加正偏移。

原文字符串不改成24:30。实际资源查询得到和歌山到85320秒、发88200秒；新宫9:35为120900秒。9月28日夜行仍属于9月28日服务日期，详情中次日时刻由秒数派生，历史地图沿用原服务日期。Swift运行时校验新增字段形状，旧资源需要重建。

统一入口：

```sh
python3 ios/tools/rebuild-reviewed-train-timetable.py
```

该入口按依赖顺序重建已审阅输入，刷新跨批次复用服务的最早／最新证据日期，验证、生成SQLite、检查输入快照并更新覆盖、路线、历史对齐和迁移审计。只消费明确add日期，不据首末日期填充中间运行日。它不自动把网上候选升级为已核实事实。
