# Codebase structure review — 2026-11-05

This is phase 1 of the codebase-cleanup session. It is a read-only review and a plan. Phase 2 does the moves and deletions in waves, and only after the in-flight branches have merged into main: route-feasibility, integration-fixes, app-control/devtools and the perf branches (graph, stats, resolution, network store). Each wave uses `git mv`, gets one commit, and is followed by an incremental build of the app, RailDiagnostics and `swift build`, plus the focused tests that touch it and `node app/scripts/build/build-port-fixtures.mjs --check`. Nothing in this plan changes behavior. Work that would change behavior is listed under **Follow-ups**.

**How the evidence was gathered.** Seven area scouts ran in parallel. Each candidate below was then re-checked with `git grep` against the whole tree, and with build membership. The app and both test bundles are `PBXFileSystemSynchronizedRootGroup` with no membership exceptions. RailDiagnostics is generated by xcodegen from `ios/auxiliary/RailDiagnostics/project.yml`, and RailKit is SwiftPM. Earlier sweeps are not repeated here: `docs/architecture/feature-interface-audit.md` §6 and commit 95b2b0f4e.
